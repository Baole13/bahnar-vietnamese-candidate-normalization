# Data and rights/provenance note

- Language pair: Bahnar (ISO 639-3 `bdq`) to Vietnamese.
- Domain: illustrated journalism associated with Báo ảnh Gia Lai.
- BA48 original archive: 5,094 automatically aligned pairs associated with 170 PDF URLs. The 4,876 analyzed pairs comprise 3,327 training, 768 validation, and 781 test query/reference records.
- Train/validation/test document family counts: 69/18/20; the test set uses 780 unique candidate Vietnamese sentences.
- Historical lexical fitting file: 55,324 paired records (not redistributed).
- E1 adaptation file: 50,283 historical auxiliary pairs and 3,327 BA48 training pairs (not redistributed).

This repository distributes only **derived numerical score matrices**, pseudonymous ID-level paired references, anonymous family labels, and aggregate evaluation outputs. It does not redistribute original publication PDFs, sentence texts, source code for proprietary PDF conversion, historical training records, or neural checkpoints.

Publisher site accessibility does not establish a blanket redistribution license for source texts. Original content rights remain with the relevant rights holders. The code-only MIT license does **not** purport to license third-party source materials or neural models. Licensing conditions for the derived score artifacts have not yet been independently confirmed; treat them as research outputs for inspection/reproduction, and seek agreement before downstream redistribution or relicensing.

The published ID hashes are **pseudonymous**, not cryptographically anonymized against anyone already holding the corresponding original corpus. They must not be described as anonymous personal data.
